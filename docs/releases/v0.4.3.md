# OpenFolio v0.4.3

## Release status

Draft candidate. Do not publish until the signed artifact completes the full
zero-network and large-archive workflow matrix.

## Changes since v0.4.2

- Moves the one-time legacy vector-index backfill out of Electron's main
  process so upgrade work cannot freeze navigation or search.
- Uses a durable keyset cursor and a small local marker table instead of
  rescanning every previously indexed vector for each batch.
- Adds SQLite busy handling so the isolated local-index worker and the app can
  safely share the WAL database.
- Keeps exact search available throughout the local upgrade and preserves all
  existing message embeddings.

## Required release verification

- Upgrade the real 100k-embedding archive from the signed v0.4.2 candidate.
- Search and navigate while the derived vector index is still catching up.
- Confirm the backfill resumes after quit/relaunch without re-embedding.
- Complete the full signed-artifact zero-network workflow in
  `docs/release-network-verification.md`.
