# OpenFolio v0.4.4

## What changed

- Keeps interactive searches on the immediate exact-search path while a background local embedding batch is using the model worker.
- Moves interactive reads into a dedicated local worker and prioritizes the newest query, so typing cannot build a stale search backlog.
- Adds a compact local semantic index with float reranking for fast meaning-based search on large archives.
- Makes the one-time compact-index upgrade resumable, versioned, and backed up before migration.
- Keeps embedding and index work progressing until the selected archive is complete, while reporting partial or failed index state honestly.
- Extends the zero-network runtime lock to every local utility worker.
