# OpenFolio v0.4.2

OpenFolio now has a complete search-first setup flow built around local-only
iMessage recall, with responsive meaning search across large archives.

## What changed

- Reworked onboarding into focused steps for Messages access, local indexing,
  optional Contacts matching, and semantic-search coverage.
- Added date-range and people prioritization for local embedding generation,
  including message counts, time estimates, and resumable progress.
- Fixed Full Disk Access setup so macOS authorizes the actual OpenFolio app.
- Made large Messages imports incremental so the app stays responsive.
- Isolated local ONNX embedding work from the main app process so a native model
  failure cannot crash the interface.
- Added an incremental local SQLite vector index so large hybrid searches do not
  block the app while scoring the entire archive.
- Tightened the complete Search, People, Conversations, Wrapped, and Settings
  experience around the restrained OpenFolio design system.

## Privacy and updates

Messages, Contacts matches, embeddings, and the search database stay on the
Mac. OpenFolio does not check for updates. To update, quit OpenFolio, download
the new release, and replace `OpenFolio.app` in `/Applications`; the library in
Application Support remains in place.

The GitHub release must remain a draft until the exact signed and notarized
artifact passes the documented first-run QA and PID-attributed zero-network
matrix on real macOS.
