# OpenFolio v0.4.0

OpenFolio now remembers who told you what.

- Search is the default surface, with exact and local semantic retrieval,
  filters, match reasons, citation context, and exact-message handoff.
- People, Conversations, and Wrapped use the new Editorial Archive design
  system across the Mac app and website.
- The pinned q8 `all-MiniLM-L6-v2` model ships in the app. Exact search remains
  available if semantic assets cannot load.
- The installed app removes hosted AI, network connectors, automatic updates,
  runtime model downloads, hosted auth, and external HTTP(S) handoff paths.
- Updates are manual. Replacing the app leaves the local library in Application
  Support in place.
- Dependency advisories are resolved, and the release pipeline now scans the
  packaged app before staging a draft release.

The GitHub release must remain a draft until the exact signed/notarized artifact
passes PID-attributed zero-traffic testing on real macOS.
