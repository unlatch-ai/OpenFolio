# Getting Started

## Install

1. Download the latest macOS release from [GitHub Releases](https://github.com/unlatch-ai/OpenFolio/releases/latest).
2. Move `OpenFolio.app` into `/Applications`.
3. Launch the app.
4. Grant Full Disk Access when macOS asks. OpenFolio needs read-only access to
   the Messages database already stored on your Mac.
5. Let exact search prepare enough records, then try something you remember.
6. Optionally allow Contacts access to replace phone numbers and email handles
   with names.

No OpenFolio account, cloud service, or API key is required.

## Search readiness

OpenFolio prepares exact search and local semantic search separately. Exact
word search remains available while meaning-based matches are still being
prepared, or if the local semantic model is unavailable.

The semantic index uses a bundled q8 `all-MiniLM-L6-v2` ONNX model. Model files
and the search index stay on the Mac; there is no remote-model fallback.

## Update manually

OpenFolio has no background updater. To update:

1. Quit OpenFolio.
2. Download the newest release.
3. Replace the existing app in `/Applications`.
4. Open the new version.

Your imported archive, index, and settings live in macOS Application Support,
outside the app bundle. Replacing the app does not move or erase that data.

## What to search for

Try a literal memory rather than a question that asks the app to make a
judgment:

- `the dumpling place Maya liked in the Richmond`
- `flight number for Sam's wedding`
- `messages about the lease renewal`
- `"garage code"`

Results are source records, not generated answers. Open a result to verify the
cited message in its original conversation.
