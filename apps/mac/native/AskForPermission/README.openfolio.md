# AskForPermission Vendor Notes

This directory vendors `riko2chen/AskForPermission` at commit
`91f4dde33f9f5dd58a89d72f3f05aa4b149a1f0e`.

OpenFolio customizes `PermissionCenter` so a bundled helper app can guide the
user to grant Full Disk Access to the main `OpenFolio.app` bundle, not to the
helper process itself.
